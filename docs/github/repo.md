# GitHub settings of FriendsOfKubernetes/sextant

Applied by hand or with `gh` after the repository exists (the commands below change the repository — run them
deliberately).

## Description

Desktop Kubernetes client in Rust (Tauri 2), an alternative to Lens: live resources, logs, shells, port forwarding, metrics and Helm.

## Topics

kubernetes, k8s, kubernetes-client, kubernetes-dashboard, kubernetes-ide, lens-alternative, desktop-app, tauri, tauri2, rust, kube-rs, react, typescript, helm, devops
