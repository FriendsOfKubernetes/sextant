# FriendsOfKubernetes

Open-source tools for people who run their own Kubernetes clusters — made for ourselves and our team, shared with
anyone who finds them useful.

## Projects

### [Sextant](https://github.com/FriendsOfKubernetes/sextant)

A desktop Kubernetes client in Rust (Tauri 2), in the spirit of Lens: clusters from your kubeconfig, live resource
tables, details and YAML editing, logs, shells in containers, a local terminal bound to the cluster, port
forwarding, CPU/memory metrics with Prometheus charts and Helm releases. Linux, macOS and Windows.
