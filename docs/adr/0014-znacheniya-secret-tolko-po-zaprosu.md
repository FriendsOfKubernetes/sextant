# ADR-0014: Значения Secret не доходят до окна, пока их не попросили

## Контекст

Секрет приходил в окно целиком: base64 из `data` лежал в каждом снапшоте и дельте таблицы и в watch панели деталей, а скрывался только на экране. Правило проекта — «секреты не уходят во фронтенд, кроме показа по клику».

## Решение

Ядро при сериализации core/v1 Secret заменяет каждое значение `data` и `stringData` на `""` (ключи остаются), добавляет в `metadata.annotations` маркер `sextant.dev/values-hidden: "true"` и вырезает `kubectl.kubernetes.io/last-applied-configuration`. Это действует и для watch, и для `resource_get`. Значение одного ключа окно запрашивает командой `secret_value(clusterId, namespace, name, key)`: ядро отдаёт его декодированным в UTF-8, не-UTF-8 даёт `invalid` с текстом «binary value, N bytes». «Edit» Secret — явное действие, оно загружает объект целиком командой `resource_get_full`, и редактор вызывает её только для Secret. Сохранение (replace и apply) текста с маркером отклоняется кодом `invalid`: «reload the secret before saving». После сохранения редактор перечитывает объект через `resource_get_full`.

Заменяет ADR-0004 в части «данные Secret приходят во фронтенд вместе с остальными объектами».

## Почему

- Маскирование в окне (`maskSecret`, `maskedAnnotation`), как было, отвергнуто: данные всё равно лежат в памяти окна и в каждом сообщении, а правило проекта про них самих, а не про то, что нарисовано.
- Загружать Secret целиком по «показать» отвергнуто: ради одного ключа в окно ушли бы все.
- Маркер нужен, потому что пустая строка — допустимое значение, и по ней нельзя отличить «скрыто» от «пусто». Без маркера правка скрытого объекта и сохранение затёрли бы настоящие значения пустыми.

## Последствия

- Любая новая функция, которой нужны данные Secret, идёт через `secret_value` или `resource_get_full`. Обычные ответы про них ничего не знают.
- Каждый показ значения — отдельный запрос к кластеру. Бинарные значения показать нельзя, только прочитать длину из ошибки.
- Маркер виден в YAML-просмотре и в аннотациях. Скопированный оттуда текст не сохранится, и это сделано намеренно.
- Просмотр Secret больше не показывает `last-applied-configuration`: вырезание делает backend. Объект целиком (Edit) его по-прежнему содержит.
- Helm не затронут: его Secret'ы читает ядро, в окно идёт `HelmReleaseDetail`.
