# ADR-0029: Сохранённый вход в Argo CD лежит в хранилище ОС (`keyring`) в приложении

## Контекст

Вход в Argo CD можно сохранить (G04), чтобы не вводить его заново. Данные секретные: пароль или API-токен. Настройки приложения лежат в `settings.json` (ADR-0017), ядро по ADR-0002 не зависит от ОС.

## Решение

Сохранением занимается крейт `keyring` (Keychain / Credential Manager / Secret Service) в приложении `src-tauri`, не в ядре. Запись: сервис `sextant`, пользователь `argocd:<clusterId>:<namespace>` (пара кластер + неймспейс Argo CD), значение — JSON `{username,password}` или `{token}`. Запись делает флажок «Remember» в окне входа; «Forget» (`argocd_logout(clusterId, { forget })`) удаляет её. Без «Remember» вход живёт до закрытия приложения. Токен сессии — только в памяти (`AppState.argocd`). На Linux `keyring` работает через libdbus, который уже нужен `tao`. Сохранённый вход применяется автоматически (ADR-0028).

## Почему

- В `settings.json` ничего секретного не пишем (так записано в спецификации); вариант «хранить там» отвергнут, причина кроме секретности в материалах не названа.
- В ядре хранение отвергнуто: ядро без зависимостей ОС (ADR-0002).
- Другие варианты (зашифрованный файл проекта, пароль только в памяти) в материалах не названы.
- Спецификация называет ключ `sextant:argocd:<clusterId>:<namespace>`, а контракт и итог таска 04 — сервис `sextant` и пользователя `argocd:<clusterId>:<namespace>`. Принято второе: оно записано как построенное.

## Последствия

- Хранится сам пароль (`{username,password}`), а не только токен сессии. Утечка из хранилища ОС раскрывает пароль, а не краткий токен.
- На Linux нужен работающий Secret Service; что будет без него, в материалах не описано.
- Тест хранилища идёт на подставном бэкенде; реальные Keychain, Credential Manager и Secret Service на трёх ОС в материалах не проверены.
- Запись привязана к `clusterId` и неймспейсу: другая установка или другой кластер потребуют нового входа. Что происходит с записью удалённого кластера, в материалах не описано.
- Новая зависимость `keyring` в `src-tauri/Cargo.toml`; сборка под три ОС должна её тянуть.
