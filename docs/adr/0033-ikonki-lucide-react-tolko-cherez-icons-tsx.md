# ADR-0033: Иконки — набор lucide-react, подключённый только через общий модуль иконок

## Контекст

В приложении не было ни библиотеки иконок, ни SVG в JSX: значки действий — текстовые глифы (≡, >_, ⇄, ✎, ×, ↻, ⏸, ⋮, ⚙ и другие) в строке `ActionDef.icon`. В боковом меню иконок не было вовсе. Для 0.4.0 нужны единые иконки у кнопок действий, у глазика Show/Hide и у разделов и пунктов меню. CSP уже разрешает `img-src data:`, но сеть и внешние ресурсы для интерфейса не используются.

## Решение

Берём `lucide-react` (ISC, SVG-компоненты, работает с React 19). Фичи его не импортируют: все иконки собраны в одном общем модуле под собственными именами (`IconName`), а действия, пункты меню и страницы называют иконку по этому имени. Имя вне набора рисуется текстом как прежний глиф (совместимость с тестами и старыми регистрациями). SVG скрыты от доступности и без `<title>`: текст кнопки или пункта меню остаётся ровно тем, что был.

## Почему

- Иконочный шрифт отвергнут: единый контурный стиль, `currentColor` и отсутствие шрифтов и сети нужны прямо (так записано в спецификации); шрифт — лишний ресурс и ещё одна точка отказа.
- Оставить текстовые глифы отвергнуто: их и заменяем, потому что набор разнородный, а у разделов меню подходящих глифов нет. Глифы остались только как запасной путь.
- Свои SVG-файлы с импортом как компонентов отвергнуты: в проекте нет плагина для этого (`vite-plugin-svgr` не стоит), а набор из десятков иконок пришлось бы рисовать и поддерживать самим. Прямо в материалах это не сравнивалось, довод следует из состояния проекта.
- Прямой импорт `lucide-react` из фич отвергнут: замена набора тогда правила бы десятки файлов, а так — один модуль.
- Логотипы Flux и Argo CD не берём: на знаки есть лицензии. Для их разделов выбраны близкие по смыслу иконки.

## Последствия

- Имена иконок образуют закрытое объединение, и это контракт. Фиче, которой нужна новая иконка, придётся править общий модуль; в этой сборке таски меню и полосы его не правили и при нехватке имени останавливались. Основа собрала имена наперёд, часть неиспользуемых позже удалена.
- Новая зависимость в `package.json`; в бандл попадают только используемые иконки.
- Значки Flux и Argo CD не узнаются по бренду: «refresh/flow» и «git-branch/rocket» только намекают.
- Смена набора — правка одного модуля и таблицы соответствий имён, но вид всего интерфейса сменится разом.
- Тесты и e2e ищут кнопки по доступному имени, поэтому кнопка из одной иконки без подписи — ошибка; обязанность подписи лежит на `Button` (ADR-0034).
