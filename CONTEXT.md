# Sextant

Настольный клиент Kubernetes для своих кластеров: список кластеров из kubeconfig, таблицы ресурсов, детали, логи, оболочки в контейнеры, проброс портов, метрики и Helm в одном окне.

## Язык

**Кластер**:
Одна запись списка слева: один контекст из kubeconfig, а не отдельный сервер Kubernetes. Два контекста на один сервер — два кластера.
_Избегать_: подключение, сервер, профиль

**Источник kubeconfig**:
Откуда приложение берёт контексты: путь по умолчанию, переменная `KUBECONFIG`, добавленный файл или вставленный текст. Один источник даёт несколько кластеров.
_Избегать_: конфиг, kubeconfig-файл

**Источник с ошибкой**:
Источник kubeconfig, который не удалось прочитать или разобрать. Его кластеры не появляются, остальные работают; ошибка видна рядом с источником в рейле и в Settings, а не только на экране «нет кластеров».
_Избегать_: битый конфиг, пропущенный файл

**Рейл**:
Узкая колонка слева со списком кластеров, с цветными метками и статусом подключения.
_Избегать_: сайдбар кластеров, панель кластеров

**Вид ресурса**:
Тип объектов Kubernetes, например Pods или Deployments, включая типы, добавленные через CRD. По виду строится таблица.
_Избегать_: тип ресурса, сущность, kind (в разговоре с пользователем)

**Подписка**:
Живое наблюдение (watch) за видом в выбранных неймспейсах с селекторами: сперва снапшот, который уходит сразу, потом изменения пачками не чаще раза в 250 мс. Один из видов потока. Таблица, детали и события обновляются только через подписки.
_Избегать_: опрос, обновление по кнопке

**Поток**:
Одна живая линия данных от ядра к окну: подписка, логи пода, оболочка в контейнер или локальный терминал. Идентификатор (`streamId`) создаёт окно и слушает его до запуска, поэтому начало данных не теряется. Потоки закрываются при отключении кластера, закрытии окна и перезагрузке страницы; проброс потоком не называется.
_Избегать_: стрим, канал

**Discovery на кластер**:
Один обход API-групп кластера, из которого берутся все виды ресурсов. Результат общий для всех подписок; встроенным видам он для старта не нужен, а колонки CRD читаются отдельно, когда открыт вид.
_Избегать_: сканирование, обновление видов

**Раздел**:
Группа в дереве слева: Workloads, Config, Network, Storage, Access Control и так далее. Раздел объединяет виды и страницы.
_Избегать_: категория, меню

**Страница**:
Содержимое пункта дерева, которое не является таблицей одного вида: обзор, события, Helm, Port Forwarding, настройки.
_Избегать_: экран, вкладка

**Панель деталей**:
Выезжающая справа панель выбранного объекта: метаданные, поля вида, события, YAML.
_Избегать_: инспектор, боковая панель

**Док**:
Нижняя область с вкладками: логи, оболочка в контейнер, локальный терминал, создание и правка YAML. Терминал — лишь один из типов вкладок дока.
_Избегать_: консоль, нижняя панель, терминал

**Проброс**:
Локальный порт на этой машине, соединённый с портом пода или сервиса в кластере (port-forward). Сидит только на 127.0.0.1.
_Избегать_: туннель, прокси

**Источник текущих значений**:
Откуда берутся числа CPU и памяти в таблицах: metrics-server или последняя точка из Prometheus. Графики всегда из Prometheus, и это отдельная настройка.
_Избегать_: метрики вообще, монитор

**Релиз**:
Установленный в кластер Helm-чарт под своим именем и с историей ревизий. К релизу на GitHub, из которого приходит обновление приложения, отношения не имеет.
_Избегать_: деплой, установка, приложение

**Обновление**:
Новая версия самого Sextant: приложение проверяет `latest.json` в релизе на GitHub, показывает версию и заметки и ставит её по «Install and restart». Подписано ключом проекта, а не подписью ОС. На Linux обновляется AppImage, `.deb` — пакетом.
_Избегать_: апдейт, релиз (это слово занято Helm)

**Маркер скрытых значений Secret**:
Аннотация `sextant.dev/values-hidden: "true"` в Secret, пришедшем в окно: значения `data` и `stringData` в нём пустые, ключи на месте. Объект с маркером не сохраняется; значение запрашивается по одному ключу, а правка Secret загружает объект целиком.
_Избегать_: маскирование, замаскированный Secret

**Предпросмотр drain**:
Список подов узла перед освобождением узла: будут выселены, без контроллера, с emptyDir, принадлежат DaemonSet. Поды без контроллера и с emptyDir трогаются только при отметках «force» и «delete emptyDir data».
_Избегать_: проверка узла, dry-run

**Схема редактора**:
Набор цветов подсветки YAML: Auto, One Dark, GitHub Dark, GitHub Light, Dracula, Nord, Solarized Dark, Solarized Light. Auto берёт One Dark в тёмной теме приложения и GitHub Light в светлой. Выбор общий для всех редакторов и просмотров YAML и хранится в настройках.
_Избегать_: тема редактора (тема — светлая или тёмная всего приложения)

**Нечитаемые настройки**:
Файл настроек, который не прочитался или не разобрался. Приложение копирует его в `settings.json.bak-<время>` и стартует с умолчаниями; при отказе в доступе запись отключена, и настройки живут до закрытия окна. В окне баннер с путём.
_Избегать_: сброс настроек

**Слой**:
Этап набора функций, а не архитектурный слой: слой 1 — ядро функциональности, слой 2 — метрики, port-forward и Helm. Оба слоя входят в сборку.
_Избегать_: уровень, фаза, итерация

**Ядро**:
Часть приложения, которая умеет всё про кластеры и ничего не знает про окно. Не путать со словом «ядро» в «слой 1 — ядро».
_Избегать_: бэкенд, сервис
